# Contributing

Thanks for helping keep this list useful and fair.

## What belongs here

- **Autonomous or agentic tools** — systems that plan, use tools, or execute multi-step workflows (not plain chat UIs with no execution layer).
- **Real products or actively maintained open-source projects** — link to the official site or primary GitHub repo.
- **Objective one-line descriptions** — no hype, no superlatives; state what it does in plain language.

## Pull requests

1. Add your entry **in alphabetical order** within the correct category (or propose a new category in the PR description if none fit).
2. Use this format: `- [Name](https://example.com) — Short neutral description.`
3. If you are affiliated with the product, say so in the PR.
4. Fix any broken links you notice while editing.

## What we skip

- Pure LLM wrappers with no tools, memory, or workflow automation.
- Affiliate or referral links (use canonical product URLs only).
- Dead or unmaintained projects unless historically notable (open an issue first).
