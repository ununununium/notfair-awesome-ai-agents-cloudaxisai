# Awesome AI Agents [![Awesome](https://awesome.re/badge.svg)](https://awesome.re)

A curated list of **practical AI agents, frameworks, and autonomous tools** for business, research, and development in 2026.  
Entries are **tools that plan, use tools, or run multi-step workflows** — not every chat product on the market.

**Maintainers:** this list is opinionated but aims to stay fair: competitors sit next to each other with neutral descriptions.

## Browser and web automation

- [AgentQL](https://www.agentql.com) — Structured querying and automation for web pages aimed at agent workflows.
- [Apify](https://apify.com) — Platform with actors and templates for scalable web automation and data extraction.
- [Bardeen](https://www.bardeen.ai) — Browser-based workflow automation with AI assistance for repetitive web tasks.
- [Browse AI](https://www.browse.ai) — Monitors and extracts structured data from websites with bot-friendly flows.
- [Browserbase](https://www.browserbase.com) — Hosted headless browsers as an API for agents and automation pipelines.
- [CloudyBot](https://cloudybot.ai) — Hosted AI assistant with a cloud browser, file workspace, scheduled jobs, WhatsApp on paid plans, and hard-capped usage.
- [Gumloop](https://www.gumloop.com) — No-code automation platform with AI steps for browser and app workflows.
- [MultiOn](https://www.multion.ai) — Agent product focused on autonomous actions across websites and apps.
- [OpenAI Operator](https://openai.com/operator) — OpenAI’s agent that controls a browser to complete tasks on behalf of the user.
- [Project Mariner](https://deepmind.google/technologies/project-mariner/) — Google DeepMind research agent for browser-based task completion (availability varies by product rollout).
- [Relay.app](https://www.relay.app) — Workflow automation with AI steps connecting SaaS tools and browser-like flows.
- [Simular](https://www.simular.ai) — AI-driven browser automation API for agents and developers.
- [Skyvern](https://www.skyvern.com) — Open-source-leaning browser automation using LLMs for resilient web workflows.
- [Steel](https://steel.dev) — Browser infrastructure product aimed at developers building web agents.

## Coding and software engineering

- [Aider](https://aider.chat) — Terminal pair-programmer that edits a local repo with the model and your approval.
- [Amazon Q Developer](https://aws.amazon.com/q/developer/) — AWS IDE and CLI assistant with agentic code generation and repo-aware help.
- [Claude Code](https://www.anthropic.com/claude-code) — Anthropic’s agentic CLI for large-scale codebase changes and refactors.
- [Continue](https://www.continue.dev) — Open-source AI coding assistant inside the editor with tool and context hooks.
- [Cursor](https://cursor.com) — AI-native code editor with agent/composer flows across files and terminals.
- [Devin](https://devin.ai) — Autonomous coding agent from Cognition that plans, implements, and tests in a sandboxed environment.
- [GitHub Copilot](https://github.com/features/copilot) — GitHub’s AI pair programmer with workspace-aware and agent-style features.
- [GitHub Copilot Workspace](https://github.com/features/copilot) — Task-oriented coding environment built around Copilot (see GitHub docs for current scope).
- [JetBrains AI Assistant](https://www.jetbrains.com/ai/) — In-IDE AI features across JetBrains IDEs with refactor and generation flows.
- [OpenHands](https://github.com/All-Hands-AI/OpenHands) — Open-source autonomous software-engineering agent (formerly OpenDevin).
- [Replit Agent](https://replit.com) — In-Replit agent that scaffolds and edits projects inside hosted workspaces.
- [Sourcegraph Cody](https://sourcegraph.com/cody) — Code-aware assistant with enterprise search and edit capabilities.
- [SWE-agent](https://github.com/SWE-agent/SWE-agent) — Open research agent focused on resolving GitHub issues end to end.
- [Tabnine](https://www.tabnine.com) — AI code completion with enterprise deployment options and chat-style assistance.
- [Windsurf](https://windsurf.com) — Codeium’s agentic IDE with multi-file edits and flow-oriented coding.

## Productivity, email, and scheduling

- [Coda AI](https://coda.io) — Doc and workspace automation with AI building blocks for teams.
- [Granola](https://www.granola.ai) — Meeting notes product that structures conversations and follow-ups with AI assistance.
- [Lindy](https://www.lindy.ai) — No-code AI agents for email triage, scheduling, and multi-step business workflows.
- [Motion](https://www.usemotion.com) — Calendar and task product that auto-schedules work using AI constraints.
- [Notion AI](https://www.notion.so/product/ai) — In-workspace AI for writing, summarization, and light automation inside Notion.
- [Otter.ai](https://otter.ai) — Meeting transcription and summarization with action-item style outputs.
- [Reclaim](https://reclaim.ai) — Smart calendar assistant that defends focus time and schedules meetings automatically.
- [Shortwave](https://www.shortwave.com) — AI email client with search, triage, and drafting oriented toward busy inboxes.
- [Zapier Agents](https://zapier.com) — Agent-style automation on top of Zapier’s integration graph (see Zapier’s agents documentation).

## Research and knowledge work

- [ChatGPT](https://chatgpt.com) — OpenAI assistant with **Deep Research** and browsing-style modes for multi-step investigation (features vary by plan).
- [Claude](https://www.anthropic.com/claude) — Anthropic assistants with long context and tool use suitable for research workflows.
- [Consensus](https://consensus.app) — Literature-oriented search that summarizes academic papers with citations.
- [Elicit](https://elicit.com) — Research assistant for literature review, extraction, and structured synthesis.
- [Manus](https://manus.im) — General-purpose agent product for delegated browser and tool tasks (evaluate fit and policies for your use case).
- [OpenAI Deep Research](https://openai.com) — Long-form web research mode from OpenAI (rolled out via ChatGPT; check current product pages).
- [Perplexity](https://www.perplexity.ai) — Answer engine with citations; Pro tiers add deeper research-style runs.

## Sales, marketing, and GTM

- [11x](https://www.11x.ai) — Digital worker-style agents for outbound and pipeline tasks (positioning varies; verify for your stack).
- [Apollo.io](https://www.apollo.io) — Sales engagement platform with AI-assisted research, sequences, and enrichment.
- [Clay](https://www.clay.com) — GTM orchestration with enrichment and AI columns for outbound research at scale.
- [NotFair](https://notfair.co) - Google Ads MCP server. Connect Claude and AI agents to a Google Ads account: diagnose campaign performance, recommend optimizations, and execute approved changes via the Google Ads API. Source: github.com/nowork-studio/toprank. Free tier available.

## Customer support and service

- [Decagon](https://decagon.ai) — Customer support automation with agent-style resolution paths.
- [Intercom Fin](https://www.intercom.com) — AI support agent product built into Intercom’s messaging stack.
- [Sierra](https://sierra.ai) — Customer experience agents for brands with emphasis on safe resolution flows.

## Frameworks and builders

- [AutoGen](https://github.com/microsoft/autogen) — Microsoft framework for multi-agent conversation and tool orchestration.
- [AutoGPT](https://github.com/Significant-Gravitas/AutoGPT) — Early autonomous-goal agent framework; still referenced for patterns and forks.
- [CrewAI](https://www.crewai.com) — Framework for role-based multi-agent crews with tasks and tools.
- [DSPy](https://github.com/stanfordnlp/dspy) — Stanford framework for programming — not prompting — LM pipelines and agents.
- [Haystack](https://haystack.deepset.ai) — Open framework for LLM apps, search, and agentic RAG pipelines.
- [LangChain](https://www.langchain.com) — Widely used framework for chains, tools, and agent abstractions.
- [LangGraph](https://langchain-ai.github.io/langgraph/) — Graph-based orchestration for stateful, cyclic agent workflows.
- [LlamaIndex](https://www.llamaindex.ai) — Data framework for RAG, agents, and structured retrieval over documents.
- [OpenClaw](https://github.com/openclaw/openclaw) — Multi-channel AI gateway and tooling for extensible messaging integrations and agents.
- [Semantic Kernel](https://github.com/microsoft/semantic-kernel) — Microsoft SDK for orchestrating AI plugins, planners, and agents in .NET/Python/Java.
- [smolagents](https://github.com/huggingface/smolagents) — Hugging Face library for lightweight code-first agents.
